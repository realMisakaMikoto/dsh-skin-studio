适配 **DeepSeek Harness Windows 桌面版 0.2.0-rc.2** 的正式版更新。本仓库及 npm 的 `dsh-skin-studio` 从 0.7.0 起维护桌面版，接续原来已停止维护的 WebUI 版本。

## 主要更新

- 完整六标签工作室：皮肤库、基础编辑、界面组件、素材替换、文案、导入导出
- 内置 17 套主题，包含 3 套基础预设、13 套虹咲角色主题和 1 套全团主题，完整素材随包提供
- 支持浅深配色、OKLCH 生成、背景图片与静音循环视频、WOFF2 字体、组件媒体及透明度
- 完成桌面版原生设置入口、组件点选、品牌与欢迎区素材、中英文文案和输入提示适配
- 编辑实时预览，应用后保存，取消恢复原皮肤；关闭未保存内容时明确确认
- 修复保存与预览时序、过期资源加载、React 节点重建及媒体、字体、观察器和 Blob URL 清理问题
- 提供 Windows 安装器、profile 自动备份，以及 GitHub Release 和 npm 两种下载渠道

## 安装

1. 至少启动过一次 DSH 桌面版，并安装 Node.js 22 或更新版本。
2. 下载 `dsh-skin-studio-desktop-0.7.0.zip`，解压到固定目录。
3. 保存工作并完全退出 DSH，双击解压目录中的 `install-desktop.cmd`。
4. 重新打开 DSH，进入 **左下角账号菜单 → 设置 → 通用设置 → 自定义皮肤 → 打开皮肤工作室**。

也可通过 npm 下载同版编辑器：

```sh
npm pack dsh-skin-studio@0.7.0
tar -xzf dsh-skin-studio-0.7.0.tgz
node package/scripts/install-desktop.mjs
```

无需自行构建。安装器会备份桌面 profile 并保留其他插件配置；安装后请保留解压目录。已安装 0.7.0 桌面版无需重复安装；切换渠道前先停用旧入口，避免同时启用两份。
