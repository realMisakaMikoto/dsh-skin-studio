适配 **DeepSeek Harness Windows 桌面版 0.2.0-rc.2** 的修复版本。GitHub 和 npm 统一使用 **0.7.1**，包含此前 GitHub 0.7.0 修订包中的壁纸溢出修复。

## 主要更新

- 修复壁纸装饰溢出导致整页出现额外滚动、界面可能被移出窗口的问题
- 保留会话面板原有的独立滚动行为
- 切换皮肤、恢复默认或卸载插件时，完整恢复 document 与 body 原有的滚动样式和优先级
- 同步 GitHub 与 npm 的修复内容、版本号、安装包和下载说明

## 安装与更新

1. 确保已安装 Node.js 22 或更新版本，并至少启动过一次 DSH 桌面版。
2. 下载 `dsh-skin-studio-desktop-0.7.1.zip`，解压到固定目录。
3. 保存工作并完全退出 DSH，双击解压目录中的 `install-desktop.cmd`。
4. 重新打开 DSH，从 **左下角账号菜单 → 设置 → 通用设置 → 自定义皮肤 → 打开皮肤工作室**进入。

也可通过 npm 下载相同版本：

```sh
npm pack dsh-skin-studio@0.7.1
tar -xzf dsh-skin-studio-0.7.1.tgz
node package/scripts/install-desktop.mjs
```

已有 0.7.0 的用户请使用 0.7.1 包重新运行安装器，并完整重启 DSH。无需自行构建；安装器会备份 profile 并保留其他插件配置，安装后请保留解压目录。GitHub 与 npm 任选一种渠道，切换渠道前请先停用旧入口。

## 兼容说明

- 保留 17 套内置主题、六标签编辑器及 `.dshskin` v5 格式
- 沿用现有皮肤数据库，保留用户主题和资源
- 当前运行环境已验证 Windows / DSH 0.2.0-rc.2；其他平台和桌面版本尚未验证
- npm 0.7.0 为首次桌面包，不含此次修复，请使用 0.7.1
